# Monitoring & Dérive de Modèles MLOps

## Description

Ce projet implémente une solution de monitoring continue pour détecter et visualiser la dérive (drift) d'un modèle de machine learning en production.

## Objectif

Détecter automatiquement les dérives de données (Data Drift) et de concept (Concept Drift) avant que le modèle ne devienne obsolète.

## Technologies

- **Python 3.10** : Langage de développement
- **Evidently AI** : Détection des dérives
- **Prometheus** : Stockage des métriques
- **Grafana** : Dashboarding
- **Docker** : Containerisation
